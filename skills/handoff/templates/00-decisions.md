> - Format: `- [who] Decision. — YYYY-MM-DD HH:MM <session8>`. `session8` = first 8 characters of the agent's session id, when it has one. Never the full id.

> - Before adding: grep this file and `00-state.md` for conflicts. On conflict, ask the user. Never silently supersede.
> - Change or delete a `[user]` line only on the user's word. Promote `[inferred]`/`[agent]` to `[user]` when confirmed.
> - Add sparingly: settled calls about the project only. Rationale goes in a numbered doc, never here.
> - The cap on line 1 is raised only with the user's explicit approval. Over the cap, trim first, then ask.
